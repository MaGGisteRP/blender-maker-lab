# Gridfinity Fit

Автономный генератор сетки Gridfinity под внутренние размеры ящика. Для экспорта установите [дополнение Gridfinity Fit](../../addons/Gridfinity%20Fit/README.md).

| Материал | Назначение |
| --- | --- |
| [Gridfinity Fit.blend](Gridfinity%20Fit.blend) | Генератор Geometry Nodes с редактируемыми параметрами |
| [Gridfinity Fit Пример печати.3mf](Gridfinity%20Fit%20%D0%9F%D1%80%D0%B8%D0%BC%D0%B5%D1%80%20%D0%BF%D0%B5%D1%87%D0%B0%D1%82%D0%B8.3mf) | Пример проекта для Bambu Studio |
| [STL](STL) | Отдельные детали с буквенными адресами |

Пример рассчитан на ящик **310 × 483 мм**, зазор **0,5 мм** и печатное поле **180 × 180 мм** с отступом **3 мм**. В комплекте **6 частей базы и 10 спейсеров**, распределённых по **6 столам**.

Модель не зависит от внешних материалов и декоративной сцены. Профиль пластика и готовый G-code не включены. Перед печатью проверьте размер своего ящика, раскладку и настройки слайсера; сначала сделайте пробную деталь.
